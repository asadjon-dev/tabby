# Tabby

A new tab page for Chrome, Edge and other Chromium browsers. Put your own photo or video behind your tabs, and add widgets like a clock, notes and search.

## Features

- **Photo or video wallpaper**: pick a file or drag it onto the page
- **Widgets**: favorites, clock, search, notes, weather, Pomodoro timer
- **Color themes**: choose one, or create and name your own
- **Make it yours**: fonts, accent colors, and each widget's background and text color
- **Private**: everything stays in your browser, with no account and no tracking
- **Backup**: export your setup to a file and restore it anywhere

## Install

1. Download this repo (green **Code** button → **Download ZIP**) and unzip it
2. Open `chrome://extensions` (or `edge://extensions`)
3. Turn on **Developer mode**
4. Click **Load unpacked** and pick the folder that has `manifest.json`
5. Open a new tab

## How to use

- Click the **gear** (bottom right) to open settings
- **Background tab**: add your photo or video
- **Widgets tab**: add, edit, show or hide widgets
- **Move icon** (bottom left): unlock to drag and resize widgets, then lock again

## Privacy

Tabby saves everything on your device. The only network request is the Weather widget, which asks [Open-Meteo](https://open-meteo.com) for a forecast. See [PRIVACY.md](PRIVACY.md).
